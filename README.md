# Guías Prácticas de Laboratorio

Este sitio web contiene una colección de **guías prácticas, ejercicios y recursos de apoyo** orientados al desarrollo de los laboratorios de diferentes asignaturas relacionadas con el área de programación y bases de datos.

El objetivo principal es proporcionar un espacio centralizado donde los estudiantes puedan encontrar **material práctico y de consulta** que les permita desarrollar las actividades de laboratorio de forma progresiva, reforzando los conocimientos adquiridos durante las clases.

## 📚 Asignaturas

Las guías y recursos disponibles están organizados para diferentes asignaturas, entre ellas:

* **Fundamentos de Programación**

  * Conceptos básicos de programación.
  * Variables, tipos de datos y operadores.
  * Estructuras de control.
  * Funciones y procedimientos.
  * Arreglos y estructuras básicas.
    
* **Programación Orientada a Objetos (POO)**

  * Conceptos fundamentales de programación orientada a objetos.
  * Clases, objetos, herencia, polimorfismo y encapsulamiento.
  * Colecciones y patrones de diseño.
  * Desarrollo de aplicaciones con JavaFX.
  * Acceso a datos mediante DAO y JDBC.

* **Programación de Estructuras Dinámicas (PED)**

  * Estructuras de datos.
  * Punteros y referencias.
  * Estructuras dinámicas lineales y no lineales.
  * Listas, pilas, colas y árboles.

* **Administración de Bases de Datos**

  * Conceptos fundamentales de administración de bases de datos.
  * Gestión y configuración de bases de datos.
  * Usuarios, roles y permisos.
  * Seguridad y mantenimiento.
  * Consultas y procedimientos relacionados con la administración de bases de datos.


## 🎯 Propósito

El sitio busca servir como un **recurso de apoyo para estudiantes**, proporcionando una guía clara y práctica para el desarrollo de los laboratorios y actividades de las diferentes asignaturas.

Las guías están pensadas para complementar las clases teóricas mediante **ejemplos, ejercicios y actividades prácticas**, facilitando el proceso de aprendizaje y permitiendo que cada estudiante avance de manera progresiva en el dominio de los conceptos.


> **Nota:** El contenido de este sitio tiene un propósito principalmente educativo y está orientado a servir como material de apoyo para el desarrollo de prácticas y laboratorios académicos.
